# Two-Stage CMOS Operational Amplifier

## Overview

Designed and analyzed a two-stage CMOS operational amplifier using LTspice to study transistor-level analog circuit design, differential amplification, current-mirror biasing, voltage gain, and frequency response.

## Objectives

- Design a two-stage CMOS operational amplifier
- Understand differential input stage operation
- Implement current-mirror based biasing
- Analyze DC operating conditions
- Measure voltage gain and frequency response
- Study amplifier bandwidth and stability

## Circuit

The project implements a two-stage CMOS operational amplifier consisting of a differential input stage, active-load/current-mirror circuitry, and a second gain stage.

## Key Concepts

- CMOS analog design
- Differential pair
- Current mirror
- Two-stage amplification
- Voltage gain
- Frequency response
- Bandwidth
- Biasing
- Stability

## Tools

- LTspice
- CMOS transistor-level simulation
